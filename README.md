# תרגיל למידת מכונה – פתרון באפליקציית Streamlit

פתרון מלא לתרגיל `תרגיל למידת מכונה.pdf`, מוצג כאפליקציית Streamlit אינטראקטיבית בעברית.

## הרצה

```bash
pip install -r requirements.txt
streamlit run app.py
```

## חלק א – ניבוי מחירי דיור (רגרסיה לינארית)

**נתונים:** `Project housing data .csv` – 2,999 דירות, 12 עמודות, ללא ערכים חסרים.

**הכנת הנתונים:**
- `view` (0–4) ו-`condition` (1–5) קודדו ב-One-Hot Encoding (`drop_first`).
- `yr_built` הומר לגיל הבית (`house_age`).
- `sqft_above` הוסר כי `sqft_living = sqft_above + sqft_basement` בדיוק (מולטיקולינאריות מלאה).
- חלוקה 80/20, `random_state=42`.

**ביצועים על סט המבחן:**

| מדד | ערך |
|---|---|
| R² | 0.584 |
| MAE | $148,055 |
| RMSE | $204,654 |
| MAPE | 32.3% |

**פרדיקציה:** דירה בדויה – 3 חדרי שינה, 2 חדרי רחצה, 2,000 sqft (מהם 400 מרתף), מגרש 7,500 sqft, 2 קומות, בנויה ב-1985, מצב 3, בלי נוף ובלי חוף → **כ-$489,000**. המחיר נמצא בטווח המחירים של דירות דומות בנתונים, ולכן נראה סביר.

## חלק ב – ניבוי התקפי לב (רגרסיה לוגיסטית)

**נתונים:** `heart_data.csv` – מאגר UCI Heart Disease (Cleveland), 303 מטופלים, עם המשתנים שמופיעים בתרגיל בלבד (`trestbps`→`trtbps`, `restecg`→`rest_ecg`). הוסרו 5 שורות עם `ca=4` (ערך לא חוקי) → 298 מטופלים.

**הכנת הנתונים:** `cp` ו-`rest_ecg` קודדו ב-One-Hot; `sex`, `exang` ו-`fbs` כבר בינאריים; `ca` נשאר מספרי. חלוקה 80/20 עם stratify, ונרמול עם StandardScaler.

**ביצועים על סט המבחן:**

| Accuracy | Precision | Recall | F1 | ROC-AUC |
|---|---|---|---|---|
| 0.833 | 0.806 | 0.906 | 0.853 | 0.911 |

**איזה מדד חשוב יותר?** **Recall.** False Negative פירושו מטופל בסיכון שנשלח הביתה בלי טיפול, וזה עלול לעלות בחיי אדם. False Positive עולה רק בבדיקות נוספות. לכן נעדיף Recall גבוה גם על חשבון Precision. באפליקציה יש טבלה שמראה איך הורדת סף ההחלטה מעלה את ה-Recall.

**פרדיקציה:** בטאב "פרדיקציה" מזינים מטופל בדוי ומקבלים את הסתברות הסיכון, פרשנות קלינית ואת המשתנים שהשפיעו הכי הרבה על התוצאה.
